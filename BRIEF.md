# BRIEF — mercurius-whisper

Распознавание речи на своей машине: HTTP-сервис вокруг faster-whisper с маршрутом распознавания, совместимым с
OpenAI API. Модуль необязателен: без него Меркурий распознаёт речь внешними моделями из `MEDIA_SPEECH_MODELS` или не
распознаёт её совсем.

## Назначение и границы

Модуль делает:

- загружает одну модель faster-whisper при старте и держит её в памяти;
- принимает звук по `POST /v1/audio/transcriptions` (форма multipart, как у OpenAI) и отдаёт текст;
- отвечает `200` на `GET /health` только тогда, когда модель загружена: проверка работы, а не порта;
- ограничивает размер файла, длительность распознавания и число одновременных распознаваний.

Остаётся в приложении Меркурия (`src/Infrastructure/Media/MediaModels.php`, `MediaSettings`, раздел
[модели вложений](../../brief/internet.md) основного репозитория):

- когда распознавать: голосовое и кружок сразу при получении, остальное по запросу;
- какие модели речи пробовать и в каком порядке (`MEDIA_SPEECH_MODELS`), переход к следующей при сбое;
- адрес сервиса (`MEDIA_ENDPOINTS`) и его ключ (секрет хранилища `media-endpoint-whisper`), разрешение внутреннего
  адреса владельцем; вызов адреса внутри сети хоста напрямую, мимо маршрута моделей;
- учёт вызовов в `llm_calls` с назначением `media-speech`.

Приложение вызывает свою модель речи по адресу, совместимому с OpenAI (`custom:<имя>/<модель>`), и ждёт ответ
`{"text": …}`.

## Устройство

| Путь / файл | Что делает |
|---|---|
| `GET /health` | `{"status":"ok","module":"whisper","model":"small"}` — `200`, когда модель загружена; пока грузится — `503` и `"status":"loading"`; не загрузилась — `503`, `"status":"failed"` и класс ошибки. Без токена |
| `GET /v1/models` | `{"object":"list","data":[{"id":"<модель>","object":"model","owned_by":"whisper"}]}` — загруженная модель |
| `POST /v1/audio/transcriptions` | форма multipart: `file` (обязателен), `model` (принимается и не учитывается), `language`, `prompt`, `response_format` — `json` (по умолчанию, `{"text"}`), `text`, `verbose_json` (`text`, `language`, `duration`) |
| `mercurius_whisper/__main__.py` | запуск: настройки, загрузка модели в фоне (порт открыт сразу, `/health` — `503`, пока модель грузится), остановка по SIGTERM и SIGINT |
| `mercurius_whisper/config.py` | настройки из окружения и их пределы; ошибка — код выхода 78, в сообщении имя переменной, не значение |
| `mercurius_whisper/server.py` | HTTP на `ThreadingHTTPServer`: токен, предел тела, форма, очередь, коды ответов |
| `mercurius_whisper/transcriber.py` | модель, декодирование звука, распознавание, отсев галлюцинаций, предел времени, очередь по порядку прихода |

Ошибки — в форме OpenAI API `{"error":{"message","type"}}`: `400` — форма без файла, не multipart или неизвестный
`response_format`; `401` — нет или неверен токен; `404` — другой путь; `411` — нет `Content-Length`; `413` — тело или
файл больше предела; `422` — звук не читается (причина от декодера до 300 символов); `503` — модель не готова или
очередь полна (`Retry-After`); `504` — распознавание дольше `WHISPER_TIMEOUT`; `500` — без подробностей.

### Настройки

| Переменная | По умолчанию | Что значит |
|---|---|---|
| `WHISPER_TOKEN` | — | обязательна, 16+ символов (`openssl rand -hex 24`) |
| `WHISPER_MODEL` | `small` | размер faster-whisper (`tiny`, `base`, `small`, `medium`, `large-v3`, `turbo`) или репозиторий Hugging Face `автор/имя` |
| `WHISPER_DEVICE` | `cpu` | `cpu`, `cuda` или `auto` |
| `WHISPER_COMPUTE_TYPE` | `int8` | тип вычислений CTranslate2: `int8` на процессоре, `float16` на видеокарте |
| `WHISPER_LANGUAGE` | `auto` | язык по умолчанию (`ru`, `en`…); `language` запроса важнее, если модель его знает |
| `WHISPER_THREADS` | `4` | потоков процессора на модель (1–64) |
| `WHISPER_MAX_MB` | `25` | наибольший файл, МБ (1–500) |
| `WHISPER_TIMEOUT` | `300` | секунд на одно распознавание (10–3600) |
| `WHISPER_CONCURRENCY` | `1` | распознаваний одновременно (1–16) |
| `WHISPER_QUEUE` | `8` | сколько запросов ждёт сверх них (0–256); дальше — `503` |
| `WHISPER_PORT` | `8000` | порт |
| `WHISPER_MODELS_DIR` | `/models` | каталог моделей (кеш Hugging Face) |

## Безопасность и пределы

- Без `WHISPER_TOKEN` (16+ символов) сервис не запускается (код 78); сравнение токена — `hmac.compare_digest`.
- Порт наружу не публикуется: в Меркурии сервис только в сети `internal`.
- Тело больше `WHISPER_MAX_MB` (плюс 64 КБ на поля формы) — `413` по `Content-Length`, до чтения тела; соединение
  после такого ответа закрывается.
- Распознавание дольше `WHISPER_TIMEOUT` прерывается: время проверяется между отрезками (отрезок — до 30 с звука), так
  что предел превышается не больше чем на один отрезок.
- Одновременно распознаётся `WHISPER_CONCURRENCY` файлов, остальные ждут по порядку прихода; ждущих не больше
  `WHISPER_QUEUE`, следующий получает `503` сразу.
- Звук декодируется в памяти и на диск не пишется; в журнал идут длительность, время распознавания, язык и число
  символов — без имени файла, звука и текста. Журнал клиента Hugging Face приглушён (`httpx` — с `WARNING`).
- Медленный клиент держит поток не дольше 60 с на чтение.
- Образ: пользователь `whisper` (uid 10050), корень только для чтения работает (`HOME=/tmp`, без `__pycache__`);
  модели — в томе `/models`.

## Решения

- **Совместимость с OpenAI API, а не свой формат** — приложение уже умеет звать такой адрес, и сервис годится любому
  клиенту этого API.
- **Имя** — `mercurius-whisper` (решение владельца 2026-11-23; в спецификации Меркурия раньше значилось
  `mercurius-media-whisper`), профиль compose — `whisper`.
- **HTTP-сервер — стандартная библиотека** (`ThreadingHTTPServer`, форма — `email.parser`): зависимостей кроме
  faster-whisper нет, а маршрутов три. Поток на соединение; работа процессора ограничена очередью, а не числом потоков.
- **Проверки — ruff, mypy (strict) и pytest** с подменённой моделью: CI не скачивает модели и не ставит faster-whisper.
- **Настройки против галлюцинаций — как у hermes-agent** (`tools/transcription_local.py`): VAD Silero (тишина 500 мс),
  `condition_on_previous_text=False`, `beam_size=5`, пороги `no_speech_threshold=0.6` и `log_prob_threshold=-1.0`
  передаются в faster-whisper, отрезок отбрасывается, только если он и «не речь», и с низкой уверенностью. Здесь они
  постоянные, а не настройки: без них Whisper на тишине пишет «Продолжение следует…».
- **Модель грузится один раз при старте и не выгружается:** сервис для этого и запущен; порт открывается сразу, чтобы
  первый запуск со скачиванием модели был виден в `/health` как `loading`, а не как недоступный сервис.
- **Сначала модель с диска без обращения к Hub, скачивание — только при промахе** (как у hermes): после первого
  запуска сеть не нужна.
- **`/v1/models` отдаёт загруженную модель:** другую сервис по запросу не грузит, и поле `model` запроса не учитывается
  — `MEDIA_SPEECH_MODELS=custom:whisper/<любое имя>` работает с той, что задана `WHISPER_MODEL`.
- **Предел времени между отрезками, а не прерывание потока:** распознавание идёт в CTranslate2, и его нельзя прервать
  извне; faster-whisper отдаёт отрезки по мере распознавания, проверка между ними прерывает работу.
- **`small` по умолчанию:** на 4 потоках процессора голосовое в 3,5 с распознаётся за ~6 с, сервис занимает ~0,8 ГБ
  памяти; `turbo` (large-v3-turbo) точнее, но ~1,7 ГБ памяти и в несколько раз медленнее (замеры 2026-11-23, Apple
  Silicon в Docker).
- **Версии зависимостей закреплены** (`requirements.txt`). PyAV — 14.2: faster-whisper 1.2.1 открывает файл с
  `metadata_errors=`, которого в PyAV 15 нет, а 14.2 — последняя 14.x с колёсами для Linux. Устройство `cuda` в
  настройках есть, но образ проверялся только на процессоре; для видеокарты нужны библиотеки CUDA и cuDNN в образе.

## Проверки

- `ruff check .`, `mypy` (strict, `mercurius_whisper/`), `python -m pytest -q` — `tests/`: настройки, распознавание с
  подменённой моделью (склейка, отсев галлюцинаций, язык, предел времени, очередь по порядку), HTTP (токен, пределы,
  форма, форматы ответа, коды ошибок, очередь).
- CI (`.github/workflows/ci.yml`): одна задача, Python 3.12, те же три команды; модели не скачиваются, образ не
  собирается. Изменения только в `*.md` CI не запускают.
- Вживую (2026-11-23): образ собран для arm64, запуск с `--read-only`, `--tmpfs /tmp`, `--memory 2g`,
  `no-new-privileges`; голосовое OGG/Opus по-русски распознано моделями `base`, `small` и `turbo`; тишина даёт пустой
  текст, не звук — `422`, без токена — `401`.

## Связь с Меркурием

- Сабмодуль `services/whisper/` основного репозитория; профиль compose — `whisper`, добавить в `COMPOSE_PROFILES`.
- В `.env`: `WHISPER_TOKEN` и при желании `WHISPER_MODEL`, `WHISPER_LANGUAGE`, `WHISPER_THREADS`; модели — в
  `storage/whisper`.
- В настройках агента: `MEDIA_ENDPOINTS=whisper=http://whisper:8000/v1` и `MEDIA_SPEECH_MODELS=custom:whisper/small`;
  токен — секретом хранилища `media-endpoint-whisper`.
- Спецификация модуля в основном репозитории — [модули: сервисы, MCP и скиллы](../../brief/skills-mcp.md).
