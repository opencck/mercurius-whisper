# BRIEF — mercurius-whisper

Распознавание речи на своей машине: HTTP-сервис вокруг faster-whisper с маршрутом распознавания, совместимым с
OpenAI API. Модуль необязателен: без него Меркурий распознаёт речь внешними моделями из `MEDIA_SPEECH_MODELS` или не
распознаёт её совсем.

Состояние на 2026-11-23: репозиторий создан владельцем, первый коммит — описание; кода ещё нет.

## Назначение и границы

Модуль делает:

- загружает одну модель faster-whisper при старте и держит её в памяти;
- принимает звук по `POST /v1/audio/transcriptions` (форма multipart, как у OpenAI) и отдаёт текст;
- отвечает на `GET /health` только тогда, когда модель загружена и распознаёт: проверка работы, а не порта;
- ограничивает размер файла, длительность распознавания и число одновременных распознаваний.

Остаётся в приложении Меркурия (`src/Infrastructure/Media/MediaModels.php`, `MediaSettings`, раздел
[модели вложений](../../brief/internet.md) основного репозитория):

- когда распознавать: голосовое и кружок сразу при получении, остальное по запросу;
- какие модели речи пробовать и в каком порядке (`MEDIA_SPEECH_MODELS`), переход к следующей при сбое;
- адрес сервиса (`MEDIA_ENDPOINTS`) и его ключ (секрет хранилища `media-endpoint-whisper`), разрешение внутреннего
  адреса владельцем;
- учёт вызовов в `llm_calls` с назначением `media-speech`.

В приложении нового кода не нужно: оно уже вызывает свою модель речи по адресу, совместимому с OpenAI
(`custom:<имя>/<модель>`), и ждёт ответ `{"text": …}`.

## Устройство (план)

| Часть | Что делает |
|---|---|
| HTTP-сервер | `GET /health`, `POST /v1/audio/transcriptions`, `GET /v1/models`; токен модуля в заголовке `Authorization` |
| Распознавание | faster-whisper (CTranslate2): модель `WHISPER_MODEL`, тип вычислений `WHISPER_COMPUTE_TYPE`, устройство `WHISPER_DEVICE`; отсечение тишины (VAD) |
| Декодирование звука | faster-whisper читает OGG/Opus (голосовые Telegram), MP3, M4A, WAV через встроенный PyAV, без ffmpeg в системе |
| Модели | скачиваются один раз в том (`/models`), при старте — загрузка; без сети после первого скачивания |
| Очередь | одновременных распознаваний не больше числа, заданного настройкой; остальные ждут по порядку прихода |

Язык — Python: faster-whisper — библиотека на Python. Остальное (HTTP-сервер, проверки, CI) выбирается первым
коммитом кода и записывается в «Решения».

## Безопасность и пределы (план)

- Без `WHISPER_TOKEN` (16+ символов) сервис не запускается; сравнение токена — за постоянное время.
- Порт наружу не публикуется: сервис только в сети `internal` Меркурия.
- Файл больше `WHISPER_MAX_MB` — `413` до чтения тела целиком; распознавание дольше `WHISPER_TIMEOUT` — прерывается.
- Звук и текст не пишутся в журнал и на диск дольше запроса: временный файл удаляется сразу.
- Образ: непривилегированный пользователь, `read_only`, предел памяти; модели — в отдельном томе.

## Решения

- **Совместимость с OpenAI API, а не свой формат** — приложение уже умеет звать такой адрес, и сервис годится любому
  клиенту этого API.
- **Имя** — `mercurius-whisper` (решение владельца 2026-11-23; в спецификации Меркурия раньше значилось
  `mercurius-media-whisper`), профиль compose — `whisper`.

## Связь с Меркурием

- Сабмодуль `services/whisper/` основного репозитория; профиль compose — `whisper`, добавить в `COMPOSE_PROFILES`.
- В `.env`: `WHISPER_TOKEN`; в настройках агента — `MEDIA_ENDPOINTS=whisper=http://whisper:8000/v1` и
  `MEDIA_SPEECH_MODELS=custom:whisper/<модель>`; токен — секретом хранилища `media-endpoint-whisper`.
- Спецификация модуля в основном репозитории — [модули: сервисы, MCP и скиллы](../../brief/skills-mcp.md).
